# Duck Image Generation Prompts

Prompts para gerar os avatares de cada pato do RubberDuckAI.
Estilo base consistente: ilustração digital flat, fundo transparente ou branco,
proporções de rubber duck (brinquedo de borracha), expressão levemente cômica.

---

## ClaudeDuck

**Estilo:** Sábio, contemplativo, levemente misterioso.

```
A rubber duck toy rendered as a flat digital illustration, amber/golden yellow color,
wearing small round glasses, a tiny philosopher's beret, with a calm and thoughtful
expression, one wing raised slightly as if mid-thought, soft warm lighting,
clean white background, cute but wise aesthetic, vector art style
```

## Notas de uso

- **Tamanho recomendado:** 512×512 ou 1024×1024, fundo transparente (PNG)
- **Ferramentas sugeridas:** Midjourney, DALL-E 3, Adobe Firefly, Stable Diffusion
- **Para Midjourney:** adicione `--style raw --ar 1:1` ao final de cada prompt
- **Para DALL-E 3:** os prompts funcionam diretamente, peça "transparent background, PNG"
- **Consistência:** se usar Midjourney, gere todos na mesma sessão com `--sref` referenciando
  o primeiro gerado para manter coerência visual entre os patos
